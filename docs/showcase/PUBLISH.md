## 短介绍

灵感来的时候，先写下来。Goose Note 是一款本地优先的桌面笔记应用：打开自己的 Markdown 文件夹，用标题、清单、表格与图示整理思路；通过独立速记小窗捕捉零散想法，再让 AI 结合笔记提炼重点、继续创作。需要分享时，将笔记导出为 PDF、Word 或图片。
