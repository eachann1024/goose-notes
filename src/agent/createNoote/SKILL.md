# 新建笔记

## 适用

- 用户明确要求新建、生成或另存为一篇笔记。
- 结果应写入当前绑定笔记本的新页面。

## 不适用

- 用户要求修改当前页面。改用 `updateNote`。
- 用户只想讨论、总结或获取建议。改用 `chat`。

## 执行

- 信息不足时先询问必要信息。
- 确定标题和完整正文。
- 将新页面作为一个 `create` 操作传给 `executeBatchPlan`。
- 正文首行不重复标题。
- 未经用户要求，不读取或改动现有页面。

## 完成

- 生成审批计划后停止，等待用户确认。
- 用户确认并执行后，用一句话说明已创建。
- 计划生成失败时说明原因，不重复提交。
